# Manuel de l'Employé

**Groupe Stovax — Stovax Limited et Gazco Limited**

---

Bienvenue dans le manuel de l'employé du Groupe Stovax. Ce manuel, avec votre contrat de travail, contient des informations importantes sur ce que nous attendons de vous et ce que vous pouvez attendre de nous. Il définit également les politiques et procédures qui seront suivies dans diverses circonstances.

Les sections sont organisées par ordre alphabétique. Cliquez sur une section ci-dessous pour y accéder directement.
