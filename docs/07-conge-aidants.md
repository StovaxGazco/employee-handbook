# Section 7 : Politique et procédure de congé pour aidants

## 7.1 Politique et procédure

7.1.1 La Société reconnaît et souhaite soutenir les Employé(e)s qui auront parfois besoin de temps libre pour fournir des soins à une personne qui n'est pas une personne à charge, comme un(e) ami(e) proche ou un(e) parent(e).

7.1.2 Les raisons pour lesquelles les Employé(e)s peuvent demander un congé pour aidants incluent :

- Prendre soin d'un(e) ami(e) proche ou d'un(e) parent(e) malade ;
- Accompagner une personne dont ils/elles s'occupent à un rendez-vous non urgent, par exemple chez le médecin ou le dentiste.

## 7.2 Procédure

7.2.1 Pour bénéficier d'un congé pour aidants, les Employé(e)s doivent remplir un formulaire de demande de congé pour aidants indiquant la raison pour laquelle le congé est demandé (voir Annexe 7A ci-dessous).

## 7.3 Droit au congé

7.3.1 Le congé pour aidants est accessible à tous les Employé(e)s.

7.3.2 Le congé pour aidants est réservé aux situations réelles où les Employé(e)s sont tenus de fournir des soins. Les Employé(e)s ne doivent pas considérer le congé pour aidants comme des jours de congé supplémentaires.

7.3.3 Les Employé(e)s peuvent prendre jusqu'à 5 jours de congé pour aidants non rémunéré sur une période de 12 mois.

7.3.4 Pour avoir droit au congé pour aidants, l'Employé(e) doit donner un préavis d'une durée égale au double du temps de congé demandé. Par exemple, si une semaine de congé pour aidants est nécessaire, un préavis de deux semaines doit être donné.

7.3.5 Le congé pour aidants peut être pris en plusieurs fois, jusqu'à 5 jours, et peut donc, par exemple, correspondre à 10 demi-journées. Le congé pour aidants peut également être pris sur une base horaire.

7.3.6 Le congé pour aidants ne sera pas rémunéré pendant la période d'absence du travail.

## 7.4 Abus du droit au congé pour aidants

7.4.1 Dans le cas où la Société prend connaissance des circonstances suivantes, la Société peut envisager une action [disciplinaire](13-disciplinaire.md) :

- Lorsqu'un(e) Employé(e) a sciemment fait une demande frauduleuse de congé pour aidants ;
- Lorsqu'un(e) Employé(e) a utilisé le congé pour aidants pour des raisons autres que celles décrites à la section 7.1.2.
